# Service Marketplace Template

A modern React + Node.js service marketplace template for Gumroad and Theme Forest.

## Features

- ✅ React 18+ frontend with modern UI components
- ✅ Node.js backend with Express
- ✅ JWT authentication system
- ✅ MongoDB database integration
- ✅ Responsive design with Tailwind CSS
- ✅ Dark/light mode support
- ✅ Service listing and search functionality
- ✅ User profile management
- ✅ Basic transaction system
- ✅ Stripe payment integration ready

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
